# 🚀 SmartDeviceOptimizer

A lightweight Python utility designed to optimize your Windows device by removing unnecessary files and resetting the system to a clean state. Perfect for preparing your device for a new user or freeing up storage space quickly.

## ✨ Features
- **User-Friendly Interface**: Simple lock screen interface for easy access.
- **Secure Password Protection**: Protects your device with a custom password.
- **Efficient Data Cleaning**: Removes temporary files, photos, documents, and more.
- **Lightweight**: No external dependencies required.

## 🛠️ How It Works
1. The script launches a simulated lock screen interface.
2. Enter the correct password to proceed.
3. The tool simulates a formatting process for user confirmation.
4. Upon confirmation, it efficiently cleans your specified directories.

## 💡 Why Use This?
- **Quick Cleanup**: Instantly remove clutter from your device.
- **Easy Setup**: Just run the script and follow the prompts.
- **Customizable**: Change the default password in the code.

## ⚠️ Note
This tool is designed for optimizing your device. Please ensure you have backed up important data before running the optimization process.

## 📥 Installation
1. Clone this repository.
2. Run the script using Python:
   ```bash
   python optimizer.py
   ```

## 🔑 Default Password
The default password is `123456`. You can change it in the `optimizer.py` file.
